# Portfólio

Portfólio pessoal desenvolvido com React, TypeScript e Vite.

## Requisitos

- Node.js 26.9.0
- npm 11.19.1

## Desenvolvimento

```bash
npm ci
npm run dev
```

O servidor local abre por padrão em `http://localhost:5173`.

## Verificações

```bash
npm run build
npm run check:audio-assets
npm run build-storybook
```

O build do Storybook é gerado em `storybook-static`. O build principal é gerado em `dist`.
