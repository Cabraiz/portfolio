Tem paliativo, sim. O melhor é fazer um soft reset completo do FortiClient no nível do usuário, sem admin.

Use este primeiro:

$FortiDir = "${env:ProgramFiles}\Fortinet\FortiClient"

if (!(Test-Path $FortiDir)) {
  $FortiDir = "${env:ProgramFiles(x86)}\Fortinet\FortiClient"
}

$FortiVPN = Join-Path $FortiDir "FortiVPN.exe"
$FortiClient = Join-Path $FortiDir "FortiClient.exe"
$Tunnel = "Secure Internet Access"

Write-Host "1. Desconectando túnel..."
& $FortiVPN --cli --disconnect --tunnel $Tunnel

Start-Sleep -Seconds 8

Write-Host "2. Fechando processos de usuário do FortiClient..."
Get-Process FortiClient,FortiClientConsole,FortiTray,FortiVPN -ErrorAction SilentlyContinue |
  Stop-Process -Force -ErrorAction SilentlyContinue

Start-Sleep -Seconds 5

Write-Host "3. Limpando DNS..."
ipconfig /flushdns

Start-Sleep -Seconds 3

Write-Host "4. Reabrindo FortiClient..."
Start-Process $FortiClient

Start-Sleep -Seconds 8

Write-Host "5. Tentando conectar novamente..."
& $FortiVPN --cli --connect --tunnel $Tunnel

Start-Sleep -Seconds 15

Write-Host "6. Status:"
& $FortiVPN --cli --status --tunnel $Tunnel

Se ele conectar e cair de novo, tenta uma versão com retry, porque às vezes o primeiro SAML/IPsec fica preso e o segundo pega:

$FortiDir = "${env:ProgramFiles}\Fortinet\FortiClient"

if (!(Test-Path $FortiDir)) {
  $FortiDir = "${env:ProgramFiles(x86)}\Fortinet\FortiClient"
}

$FortiVPN = Join-Path $FortiDir "FortiVPN.exe"
$FortiClient = Join-Path $FortiDir "FortiClient.exe"
$Tunnel = "Secure Internet Access"

for ($i = 1; $i -le 5; $i++) {
  Write-Host ""
  Write-Host "===== Tentativa $i ====="

  & $FortiVPN --cli --disconnect --tunnel $Tunnel
  Start-Sleep -Seconds 8

  Get-Process FortiClient,FortiClientConsole,FortiTray,FortiVPN -ErrorAction SilentlyContinue |
    Stop-Process -Force -ErrorAction SilentlyContinue

  Start-Sleep -Seconds 5

  ipconfig /flushdns

  Start-Process $FortiClient
  Start-Sleep -Seconds 8

  & $FortiVPN --cli --connect --tunnel $Tunnel
  Start-Sleep -Seconds 20

  & $FortiVPN --cli --status --tunnel $Tunnel

  Start-Sleep -Seconds 10
}

Também vale testar trocar a rede por alguns minutos:

1. Desconecta VPN.
2. Fecha FortiClient.
3. Conecta no hotspot do celular.
4. Abre FortiClient.
5. Tenta conectar.

Se no hotspot funcionar, o problema pode ser NAT/UDP/IPsec/rede atual. Se cair igual com ParameterConfig, reforça que é bug/policy/versão.

O que não adianta tentar sem admin:

Restart-Service
Stop-Service
Start-Service
Disable-NetAdapter
Enable-NetAdapter
netsh winsock reset
netsh int ip reset
pnputil
sc stop
sc start

Esses mexem em serviço, driver, pilha TCP/IP ou adaptador. Vai pedir admin ou falhar.

O paliativo mais forte que você consegue sem admin é esse ciclo:

disconnect CLI
fechar processos de usuário
flushdns
reabrir FortiClient
conectar pela UI ou CLI
repetir 2–5 vezes
testar outra rede

Mas sendo honesto: se ele sempre cai com ParameterConfig, isso tende a voltar até atualizarem/repararem a versão/policy. O paliativo pode destravar um estado preso, mas não corrige o bug da 7.4.6.
