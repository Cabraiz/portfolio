Tem paliativo, sim. O melhor é fazer um soft reset completo do FortiClient no nível do usuário, sem admin.

Use este primeiro:

$FortiDir = "${env:ProgramFiles}\Fortinet\FortiClient"

if (!(Test-Path $FortiDir)) {
  $FortiDir = "${env:ProgramFiles(x86)}\Fortinet\FortiClient"
}

$FortiVPN = Join-Path $FortiDir "FortiVPN.exe"
$FortiClient = Join-Path $FortiDir "FortiClient.exe"
$Tunnel = "Secure Internet Access"

Write-Host "1. Desconectando túnel..."
& $FortiVPN --cli --disconnect --tunnel $Tunnel

Start-Sleep -Seconds 8

Write-Host "2. Fechando processos de usuário do FortiClient..."
Get-Process FortiClient,FortiClientConsole,FortiTray,FortiVPN -ErrorAction SilentlyContinue |
  Stop-Process -Force -ErrorAction SilentlyContinue

Start-Sleep -Seconds 5

Write-Host "3. Limpando DNS..."
ipconfig /flushdns

Start-Sleep -Seconds 3

Write-Host "4. Reabrindo FortiClient..."
Start-Process $FortiClient

Start-Sleep -Seconds 8

Write-Host "5. Tentando conectar novamente..."
& $FortiVPN --cli --connect --tunnel $Tunnel

Start-Sleep -Seconds 15

Write-Host "6. Status:"
& $FortiVPN --cli --status --tunnel $Tunnel

Se guimessenger64.node apareceu, então o erro não é “arquivo inexistente”.

Nesse caso, quando o Windows/FortiClient diz:

não foi possível encontrar o módulo especificado
guimessenger64.node
assets\main.js

normalmente significa:

o guimessenger64.node existe,
mas alguma DLL/dependência que ele precisa não carregou
OU a instalação está inconsistente
OU a versão do FortiClient está quebrada/corrompida

Ou seja: o módulo existe, mas ele não consegue ser carregado.

Rode estes comandos para pegar evidência limpa:

$FortiDir = "${env:ProgramFiles}\Fortinet\FortiClient"

if (!(Test-Path $FortiDir)) {
  $FortiDir = "${env:ProgramFiles(x86)}\Fortinet\FortiClient"
}

$Node = Get-ChildItem $FortiDir -Recurse -ErrorAction SilentlyContinue |
  Where-Object { $_.Name -eq "guimessenger64.node" } |
  Select-Object -First 1

$Node | Format-List FullName, Length, LastWriteTime

Depois:

Get-AuthenticodeSignature $Node.FullName | Format-List

E:

Get-Item $Node.FullName -Stream * -ErrorAction SilentlyContinue

Se aparecer Zone.Identifier, tenta desbloquear:

Unblock-File $Node.FullName

Mas provavelmente vai falhar por estar em Program Files ou nem vai resolver.
