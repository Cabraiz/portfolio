Recorte uma pasta de um repositório.

Cole uma URL de pasta no formato /tree/branch/caminho/da/pasta. O servidor local baixa o ZIP da branch, extrai apenas o diretório escolhido e salva no temp real do Windows. Ao concluir, a pasta final é aberta automaticamente.

Exemplo de formato: https://github.com/owner/repository/tree/main/tools/viewer

Repositório privado ou limite de API? Use token opcional

O token é enviado apenas para o servidor local durante esta requisição.
